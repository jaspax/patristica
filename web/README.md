# Patristica web app

Next.js (App Router, TypeScript) frontend for Patristica. See the repository
`README.md` and `CLAUDE.md` ("Web app") for setup.

```bash
nvm use            # Node version from .nvmrc
npm ci
npm run dev        # http://localhost:3000
npm test           # Vitest
npm run lint
npm run typecheck
npm run build
```
